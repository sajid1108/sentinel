# AegisShift landing page

Static page, no build step. Open `index.html` in a browser (the videos load from this folder).

- Home: the world-tree video with the Demo 2 ring overlaid.
- Stance change: drag the abuse probability; the tree cross-fades healthy → middle → dying.
- Demos: the three demo decisions replayed from recorded values (Demo 1 healthy, Demo 3 middle, Demo 2 dying).
- Try an order: answers replayed from `try-grid.json`, recorded from the real API by `scripts/record_try_grid.py` (serve the folder over HTTP; `fetch` does not work from `file://`).
- Results and Disclosures: the synthetic backtest and the model-card disclosures.
