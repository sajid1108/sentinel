# SENTINEL — Deviations from Frozen Architecture

This file records every intentional deviation from `docs/ARCHITECTURE.md`.
Numbers are stable identifiers; a resolved deviation keeps its number and is marked as removed.

| # | Section | Deviation | Reason |
|---|---------|-----------|--------|
| 1 | — | *Removed.* The backend now runs on Python 3.12.2 as specified (`requires-python = "==3.12.*"`). | Phase 1 review B1: the lockfile installed unchanged on 3.12 and all tests passed. |
| 2 | Non-negotiable 16 | Dependency pins are the latest versions available when the project was set up (for example pandas 3.0.5, scikit-learn 1.9.1), not versions named in the contract. | The contract asks for exact pins but names none. `tests/unit/test_environment.py` asserts `sklearn.__version__` equals the pin so artifacts cannot be loaded under a different version silently. |
